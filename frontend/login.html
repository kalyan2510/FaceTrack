Password help

For this college project, password resets are handled by the project administrator on the Flask backend.

Run this command in backend/ to reset the default administrator account:
python -c "from database import init_db; init_db()"

Or delete backend/database/attendance.db and restart the backend to recreate the seeded administrator (admin@facetrack.com / Admin@123). This deletes all local records.
